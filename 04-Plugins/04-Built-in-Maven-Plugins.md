# Built-in Maven Plugins

Maven provides many standard plugins for common build tasks. These plugins are used automatically or can be invoked directly when required.

---

## Common Maven Plugins

| Plugin | Main Purpose |
|---|---|
| `maven-clean-plugin` | Deletes previous build output |
| `maven-resources-plugin` | Copies project resources |
| `maven-compiler-plugin` | Compiles Java source code |
| `maven-surefire-plugin` | Runs unit tests |
| `maven-jar-plugin` | Creates JAR files |
| `maven-install-plugin` | Installs artifacts into the local repository |
| `maven-deploy-plugin` | Deploys artifacts to a remote repository |

---

## 1. Maven Clean Plugin

Used to remove files generated by previous builds.

Command:

    mvn clean

It normally deletes:

    target/

We used this command in our Maven project:

    mvn clean

---

## 2. Maven Resources Plugin

Used to copy project resources such as files from:

    src/main/resources

and:

    src/test/resources

into the appropriate build directories.

Maven may show this plugin during:

    mvn compile
    mvn test
    mvn package

---

## 3. Maven Compiler Plugin

Used to compile Java source code.

It converts:

    .java

files into:

    .class

files.

Example:

    src/main/java/com/example/App.java

is compiled into:

    target/classes/com/example/App.class

---

## 4. Maven Surefire Plugin

Used to run unit tests during the `test` phase.

Command:

    mvn test

Our project produced:

    Tests run: 1, Failures: 0, Errors: 0, Skipped: 0

This means the test executed successfully.

Test reports are stored in:

    target/surefire-reports/

---

## 5. Maven JAR Plugin

Used to create JAR files during the `package` phase.

For our project, Maven created:

    target/maven-demo-1.0-SNAPSHOT.jar

Command:

    mvn package

---

## 6. Maven Install Plugin

Used to install the project's artifact into the local Maven repository.

Command:

    mvn install

Our project was installed under:

    ~/.m2/repository/com/example/maven-demo/1.0-SNAPSHOT/

It contained:

    maven-demo-1.0-SNAPSHOT.jar
    maven-demo-1.0-SNAPSHOT.pom

---

## 7. Maven Deploy Plugin

Used to deploy an artifact to a remote Maven repository.

It is generally used when a project needs to be shared through a remote repository.

Command:

    mvn deploy

---

# Plugin and Lifecycle Relationship

Maven lifecycle phases are associated with plugin goals.

Example:

    mvn compile
          ↓
    maven-compiler-plugin
          ↓
    compile goal

Another example:

    mvn test
          ↓
    maven-surefire-plugin
          ↓
    test goal

And:

    mvn package
          ↓
    maven-jar-plugin
          ↓
    jar goal

---

# Important Interview Point

You do not always need to explicitly declare every standard Maven plugin in `pom.xml`.

Maven has default lifecycle bindings that associate common plugins with lifecycle phases depending on the project's packaging.

However, plugins can be explicitly configured when customization is required.

---

# Key Points

- `maven-clean-plugin` → cleans the `target` directory.
- `maven-resources-plugin` → handles project resources.
- `maven-compiler-plugin` → compiles Java code.
- `maven-surefire-plugin` → runs unit tests.
- `maven-jar-plugin` → creates JAR files.
- `maven-install-plugin` → installs artifacts into the local repository.
- `maven-deploy-plugin` → deploys artifacts to a remote repository.
- Maven lifecycle phases use plugin goals to perform actual build tasks.

---

# Interview Questions

### Which plugin compiles Java code?

`maven-compiler-plugin`.

### Which plugin runs unit tests?

`maven-surefire-plugin`.

### Which plugin creates a JAR?

`maven-jar-plugin`.

### Which plugin installs an artifact into the local repository?

`maven-install-plugin`.

### Which plugin deploys an artifact to a remote repository?

`maven-deploy-plugin`.

### Are all Maven plugins required to be explicitly added to `pom.xml`?

No. Maven provides default lifecycle bindings for many standard build tasks. Explicit configuration is needed when customization is required.
